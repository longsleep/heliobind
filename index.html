Heliobind

Wi-Fi and server setup for a Growatt NEXA 2000, over Bluetooth

A newer version is ready.
Install Heliobind to use it without a network.

This browser cannot use Bluetooth from a web page. Chrome or Edge can, on Android, Windows, macOS and ChromeOS. On Linux it ships disabled: enable chrome://flags/#enable-experimental-web-platform-features, restart the browser, and reload. No browser on iOS supports it — they are all Safari underneath.

Everything here happens over Bluetooth, standing next to the device — no vendor app, no account and no network. Join the device to a Wi-Fi network, point it at a server of your choosing, and read every setting it holds.
